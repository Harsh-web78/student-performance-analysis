# Student Performance Analysis

## Project Overview

This project analyzes student performance data using Python to understand how study habits, attendance and previous academic performance relate to final scores.

## Objectives

- Analyze student performance
- Clean and inspect the dataset
- Explore relationships between variables
- Create meaningful visualizations
- Identify important patterns

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

Data Collection
↓
Data Cleaning
↓
Exploratory Data Analysis
↓
Visualization
↓
Insights

## Key Analysis

- Study hours vs final score
- Attendance vs final score
- Gender-wise performance
- Parental education vs performance
- Score distribution
